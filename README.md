# Machine Learning-Assisted Optimization of Iodide Electrolytes for Efficient Indoor Dye-Sensitized Solar Cells with Engineered Photoanodes

This repository contains the computational notebook and the primary dataset accompanying the research article *"Machine Learning-Assisted Optimization of Iodide Electrolytes for Efficient Indoor Dye-Sensitized Solar Cells with Engineered Photoanodes"*. It provides the necessary resources to reproduce the machine learning-assisted Bayesian optimisation workflows utilised in the study.

## Repository Contents

### Dataset
* **`data-bo-dssc.tsv`**: The empirical dataset comprising the experimental evaluations of various iodide-based electrolyte compositions. This tabular data serves as the foundation for training the machine learning surrogate models and validating the predicted optimal configurations.

### Computational Notebooks
The repository includes Jupyter Notebooks that document the analytical and empirical modelling procedures:

* **`DSSC_bayesian_optimization.ipynb`**: The principal notebook detailing the comprehensive Bayesian optimisation methodology applied to the dye-sensitized solar cell (DSSC) electrolyte systems. It encompasses data preprocessing, surrogate model training, and the sequential optimisation framework.

*(Note: The repository also contains the resultant CSV files containing the experimental propositions, such as `proposed_bo_experiments_jsc.csv`, `proposed_bo_experiments_pce.csv`, and `proposed_bo_experiments_voc.csv`, which are generated by the optimisation routines).*
